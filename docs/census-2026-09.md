## How to read this

- These are statements about **published package metadata**. An install hook is ordinary npm practice, not evidence of malice; the finding is that it executes at install time and deserves a look before a user runs `npx` or a client installs the server.
- `repository-mismatch` and `package-repository-missing` are provenance findings: the audit could not tie the published package back to the repository the registry declares.
- `declared-version-not-latest` is freshness, not risk.

## What this census does not cover

- **PyPI / OCI / MCPB packages** (52 servers). Not audited; not clean.
- **Remote endpoints.** The registry lists 297 package-declaring and 1846 remote-only servers; no endpoint was contacted, by design.
- **Runtime behaviour.** A static finding is not a proof of exploitability. Verification, where performed, happens only in a disposable local environment.
